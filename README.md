# LUNGTA website rebuild

A multi-page static prototype built around the approved LUNGTA identity.

## Pages
- `index.html` - homepage and brand experience
- `drop.html` - Drop 01 collection
- `product.html?p=form01` - dynamic product template
- `movement.html` - interactive Move Index
- `material.html` - material and fabric behaviour
- `lungta.html` - brand system and approved identity board

## Interaction layer
- Exact approved particle Wind Horse asset, no hand-drawn replacement
- Exact LUNGTA mark and wordmark assets
- Responsive wind field and fabric mesh canvases
- Movement mode and day-state selectors
- Bounded card tilt on fine-pointer devices
- LocalStorage prototype bag shared across pages
- Responsive mobile menu and motion-reduction support

## Deployment
The build uses relative paths and can be uploaded directly to GitHub Pages. No build step is required.

## Production note
Campaign photography in `/assets/images` remains prototype stand-in photography from the earlier build and should be replaced with original LUNGTA campaign assets before commercial launch.
